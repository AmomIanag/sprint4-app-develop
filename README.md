## Sprint 4 — App Development

Nesta Sprint, evoluímos o dashboard da Motiva,
implementando um sistema de priorização automática
para manutenção da vegetação nas rodovias.

### Funcionalidades
- Classificação automática da vegetação
- Priorização dos pontos monitorados
- Indicadores dinâmicos
- Ordenação por prioridade
- Recomendações de intervenção
